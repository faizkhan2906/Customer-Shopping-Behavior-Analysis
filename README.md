# 🛒 Customer Shopping Behavior Analysis | SQL • Python • Power BI

> An end-to-end Data Analytics project that transforms raw retail transaction data into meaningful business insights using Python, SQL Server, and Power BI.

---

## 📖 Project Overview

Understanding customer purchasing behavior is one of the most important aspects of retail analytics. Businesses rely on customer transaction data to identify purchasing trends, improve customer experience, optimize inventory, and make informed business decisions.

In this project, I performed an end-to-end data analytics workflow starting from data cleaning in Python, importing the cleaned dataset into SQL Server, solving business problems using SQL, and finally designing an interactive Power BI dashboard to visualize key insights.

To make the project more comprehensive, I also prepared a detailed project report (Word & PDF) and an executive presentation (PowerPoint) summarizing the complete analysis and business findings.

---

# 🎯 Project Objectives

- Clean and preprocess raw retail transaction data.
- Perform exploratory data analysis (EDA).
- Import cleaned data into Microsoft SQL Server.
- Solve real-world business questions using SQL.
- Create an interactive Power BI dashboard.
- Generate meaningful business insights.

# 🧹 Data Cleaning & Preprocessing

Data preprocessing was performed in **Python (Pandas)** before importing the dataset into SQL Server.

The following tasks were completed:

- Imported dataset into Jupyter Notebook
- Checked data structure and data types
- Identified missing values
- Filled missing Review Ratings using median values within each product category
- Converted purchase frequency into numeric values
- Removed unnecessary columns
- Created additional features where required
- Verified data consistency
- Exported cleaned dataset to SQL Server
